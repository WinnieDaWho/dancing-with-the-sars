05 / SOURCES & TRANSPARENCY

Science has a source.
So should the story.

Built for the Dancing with the SARs challenge. This showcase demonstrates an interface and architecture; it does not claim a validated NISAR-derived detection.

  • NASA–ISRO NISAR ↗

    Mission and radar science. NASA and ISRO jointly develop the NISAR mission.

  • Alaska Satellite Facility ↗

    Product documentation, access methods, and interpretation guidance.

  • ASF NISAR Cookbook ↗

    Reference workflows for search, access, and analysis. No upstream notebooks are bundled.

  • Bilawal Sidhu’s gods-eye-view ↗

    Target 3D globe integration. Its code is not included in this static showcase; preserve its license when adapting.

  • PostGIS ↗

    Spatial indexing and geometry/geography queries for the planned analysis service.

  • AI & data disclosure ↗

    Gemini supplied the outline. Codex assisted with the website, documentation, and illustrative media. Full provenance is in the kit.
