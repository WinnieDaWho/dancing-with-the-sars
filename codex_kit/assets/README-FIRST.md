# RHD Labs delivery kit

Start with `DELIVERY.md` for live URLs and remaining integration tasks.

- `index.html`: portable standalone showcase, with assets in `assets/`.
- `rhd-labs-7-slide-deck.pdf`: seven-slide presentation.
- `rhd-labs-7-slide-deck.pptx`: editable PowerPoint version.
- `demo-reel.mp4`: captioned 28.8-second concept reel; no generated narration.
- `demo-reel.srt` / `demo-reel.vtt`: English captions.
- `ambient-original.wav`: original procedural music bed.
- `project-source.zip`: Apache-2.0 Python/PostGIS scaffold and website.
- `submission-copy.md`: editable English portal fields and disclosures.
- `HANDOFF.md`: responsibilities, science corrections, and integration steps.
- `integration-contract.json`: suggested API provenance envelope.
- `media-production.md`: both narration directions, B-roll prompts, and edit timing.
- `qa-status.md` / `verification-results.json`: verified results and limits.

The showcase is functional as a static presentation with synthetic examples. Live scientific analysis and the full 3D/voice application are separate deliverables and must be validated before making claims about actual detections.
